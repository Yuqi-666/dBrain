# Contributing to dBrain

dBrain is source available under Apache-2.0. The owner develops and releases it independently. External pull requests are not accepted. Please do not open a fork PR; it will be closed without review. GitHub does not disable the PR entry point for this public repository.

You may report a reproducible bug or suggest a feature in an issue. The owner decides whether and when to act on it. For a security issue, use the private reporting process in [SECURITY.md](SECURITY.md) and do not put exploit details in a public issue.

The owner's development and release process is documented in [CI/CD](docs/ci-cd.md). Chinese instructions: [贡献说明](docs/zh/contributing.md).
