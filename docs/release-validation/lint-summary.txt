Why the editor was the only failing package
------------------------------------------
packages/editor was the only workspace package still using `eslint-config-next`
(never declared in its package.json; it resolved through the root hoisted
node_modules) instead of @workspace/eslint-config/react-internal, the shared
config used by every sibling React package. That made it the only package linted
with the eslint-plugin-react-hooks 7 compiler rule set (react-hooks/refs 18,
set-state-in-effect 23, immutability 1 = 42 errors) and with Next-only rules
(@next/next/no-img-element 4). Neither rule set is part of the workspace
standard: the shared config pins eslint-plugin-react-hooks 5.x, whose recommended
set contains only rules-of-hooks/exhaustive-deps. The package is a React
component library (no app router, no next.config, no next dependency), so the
shared React config is the correct one. No rule was disabled to hide a finding.
