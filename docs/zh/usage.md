# 使用手册

## 选择桌面版还是 Web 版

| 模式 | 账号与数据 |
| --- | --- |
| 桌面版 | 首次启动创建本地身份。核心内容保存在本设备，无需云端账号。 |
| Web 版 | 用服务地址注册或登录。内容和附件保存在该服务端。 |

两种模式共用工作空间界面，当前不自动同步数据。桌面本地身份不等同于 Web 账号。离线模式不保证外部网站或网络链接在断网时可用。

## 安装桌面版

从仓库的 GitHub Releases 页面下载已发布版本。草稿和候选产物供维护者使用。

选择系统与 CPU 对应的包。解压平台 ZIP 后检查附带的 `SHA256SUMS`。不要混用不同架构的安装器。

| 平台 | 安装格式与步骤 |
| --- | --- |
| Linux x64 | 用发行版包管理器安装 DEB 或 RPM。给 AppImage 执行权限后运行。 |
| Windows x64 | 运行 EXE 或 MSI，按安装器提示完成。 |
| macOS Intel | 打开 `darwin-x64` DMG，把应用复制到 Applications。 |
| macOS Apple Silicon | 打开 `darwin-arm64` DMG，把应用复制到 Applications。 |

安装包携带 Node、PocketBase 与媒体处理运行时。使用者无需安装 pnpm、Rust 或其他开发依赖。Linux 仍需满足目标发行版的 WebView、系统库与媒体解码要求。dBrain 不宣称支持所有 Linux 发行版。

以下示例中的文件名应替换为实际下载文件。

```bash
# Linux AppImage
chmod +x dBrain.AppImage
./dBrain.AppImage

# Debian / Ubuntu
sudo apt install ./dBrain.deb

# Fedora 等 RPM 系统
sudo dnf install ./dBrain.rpm
```

当前内部候选没有正式签名与公证。Windows 可能显示未知发布者或 SmartScreen 提示。macOS 可能要求在“系统设置 → 隐私与安全性”中确认“仍要打开”。只对来源已验证的包操作。设备管理策略可能阻止继续安装。

参考说明：

- [Apple 说明](https://support.apple.com/en-lamr/102445)
- [Microsoft 说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)

## 第一次进入

桌面版启动时初始化本地数据、后端与身份，然后显示工作空间。等待初始化完成。出现连接错误时使用界面的重试入口。同一数据目录不要同时运行多个实例。

Web 用户打开维护者提供的服务地址，在注册页创建应用用户，然后登录。PocketBase 运维超级管理员不是应用登录账号。页面一直加载时先联系部署维护者。维护者检查服务与代理配置。

## 工作空间与内容

1. 在工作空间选择器中选择现有空间，或用新建入口创建空间。
2. 在图谱中选择视图。右键空白画布打开添加节点菜单。
3. 为内容选择节点类型。打开编辑器填写内容或上传附件。
4. 用节点菜单和关系菜单更改语义与连接。用视图配置与筛选控制显示范围。
5. 切换到 Dashboard，用工作空间组件和数据视图组织工作。

节点类型有文本、富文本、图片、PDF、视频、音频、网页、网站、集合和数据库。关系连接两个节点。标签与语义为节点分类。工作空间是内容的范围。视图是应用显示内容的方式。

富文本编辑器里，第一次按 Ctrl+A（macOS 为 Command+A）选中当前块，第二次选中全文。复制时纯文本以 Markdown 写入剪贴板。图片等没有文字形式的节点不会写入复制的文本。

删除内容前检查菜单的作用对象是节点、关系还是选中集合。重要资料先备份。

图谱和 Dashboard 使用同一工作空间的数据。数据库内容支持表格、看板、日历、图表等数据视图。可用配置以当前界面入口和内容类型为准。媒体上传后的解析、封面和转码需要时间。失败时保留报错和文件类型，供维护者排查。

Dashboard 把界面元素放进左右两个侧栏。左侧栏放页面和工作空间，右侧栏放组件库。指针移到屏幕边缘时，对应的侧栏浮出显示。用标题栏的两个按钮把侧栏固定。侧栏内的按钮把浮动的侧栏固定，或把固定的侧栏关闭。侧栏固定时，标题栏上对应的按钮隐藏。把当前节点加入组件库，在节点编辑器标题栏选择 Dashboard 按钮。

### 附件上传

单个附件最大 2 GiB。应用按大小自动选择上传方式。使用者无需设置。

- 32 MiB 以内的文件一次上传完成。
- 大于 32 MiB 的文件按 8 MiB 分片上传。客户端只发送缺失的分片。网络中断、刷新页面或重启后端后，再次选择同一文件。上传从已完成的分片继续。
- 服务端在本机磁盘拼装分片，然后把文件存入文件库。这一步可能持续较长时间。页面显示进度。这一步关闭页面不会丢失文件。重新打开页面后可以看到结果。
- 取消上传后分片留在服务端。再次上传同一文件即可继续。

服务端在开始上传前拒绝大于 2 GiB 的文件。编辑器内图片和网页源码文本另有更小的上限（5 MiB）。这些上限与节点附件上限不同。

PDF 超过 256 MiB 时跳过解析。应用只保存文件。仍可下载和打开，但没有页数和封面。视频按磁盘流式转码。大小不影响 HLS 生成。

PDF 预览器先显示已保存的第一页封面，再用渲染出的页面替换它。预览器只读取当前页面用到的部分。它不会先下载整个文件；定位页面时直接读取页树中该页的条目，而不是把每一页的条目都读一遍，因此页面分散存储的大体积扫描件也能较快打开。预览器在你滚动到后续页面时再读取。

应用按读者和节点分别记住上次页码。重新打开节点即从该页继续。大纲按层级折叠，选择父项可展开或收起，长标题自动换行。

## 数据保存与备份

桌面版的数据库、附件、本地身份和日志保存在系统应用数据目录。通常可用标识 `cn.dbrain.desktop` 定位。实际目录以平台接口和运行日志为准。Linux 常见路径为 `$XDG_DATA_HOME/cn.dbrain.desktop`。未设置该变量时，路径为 `~/.local/share/cn.dbrain.desktop`。

备份前完全退出应用。检查后台进程已停止。把**整个应用数据目录**复制到安全位置。不要只复制数据库文件。附件和本地身份也要保留。

恢复前先保留当前目录副本。然后关闭应用，恢复匹配版本的完整数据。

Web 用户的数据由维护者备份。浏览器缓存不等同于服务端备份。dBrain 不承诺通用的跨端一键迁移。迁移需求须由维护者检查。

## 升级与卸载

已安装的桌面应用每次启动时通过 HTTPS 检查最新已发布 Release。若对应平台存在更新版本且更新包已签名，应用会下载、验证更新签名、安装并重启。检查失败时仍可离线使用。首个接入更新器的版本需要手动安装。

Tauri 当前传输完整更新包。这是版本增量升级，不是按字节差异传输的补丁。升级不替换应用数据目录。桌面运行时在版本迁移前会备份数据，并在 `backups` 目录只保留最近两次迁移快照，更早的会删除。但不能替代你的外部备份。

卸载程序与删除个人数据是两个不同的操作。不要假定卸载器会删除数据。需要删除数据时，退出应用，查看应用数据目录，先备份，再手动删除。回滚时使用旧版本的数据备份。旧版本不一定能直接打开已迁移的数据库。
